## التهيئة الآمنة

استخدم قاعدة PostgreSQL17 محلية جديدة باسم يبدأ بـ`academy_professional_demo_`، وشغّل migrations ثم API ببيئة`Demo` وملف`Football` مرة واحدة. اجعل media/keys في مجلد خاص دائم للديمو. تشغيلDLL يحتاج`ASPNETCORE_CONTENTROOT` يشير إلى مجلد`apps/api/src/Academy.Api` لقراءة الأصول؛ ملفCompose الإنتاجي يضبط مجلد التشغيل داخل الصورة بالفعل.

ثبّت`psycopg[binary]` فيvenv خاصة، ثم شغّل من جذر المستودع:

```bash
ASPNETCORE_ENVIRONMENT=Demo \
ACADEMY_DEMO_CONNECTION='Host=127.0.0.1;Port=55471;Database=academy_professional_demo_20261102;Username=academy' \
ACADEMY_DEMO_DATE=2026-11-02 \
python scripts/demo/prepare_professional_demo.py
```

البرنامج يرفض الإنتاج والخادم غير المحلي واسم القاعدة خارج النطاق وعلامة أكاديمية غير اصطناعية. التهيئة معاملة واحدة؛ إعادة التشغيل لا تكرر اللاعب أو التحصيل. لا reset أو حذف. احفظ القاعدة والسجلات داخل`output/professional-demo-20261102/runtime` المستبعد منGit، وليس`/tmp` إذا أردت استمرار الديمو بعد إعادة تشغيل الجهاز. قاعدة الديمو المحلية هذه ليست قاعدةCompose الإنتاجية.
