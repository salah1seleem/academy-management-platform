# Fictional demo portraits — V4.1

Six synthetic portraits generated with the built-in image generation tool on 20 October 2026 at the product owner's request. They do not depict known real people. Coordinated slate backgrounds; no customer uploads or externally sourced personal photographs.

The child-01/02, coach-01/02 and guardian-01/02 JPEGs are optimized 384×384 variants of individually generated originals. They are bundled in Flutter and mirrored under the Web public demo-assets directory. Only the explicitly marked Football tenant in an opted-in Demo database named academy_v4_* receives these references, and existing photos are preserved. Each portrait identifies one fictional record, not a carousel of unrelated children sharing one face. Missing portraits use the appropriate role silhouette.

These are demonstrative identities, not verification or real biometric data. Original generation output remains outside the Git repository; no reference archive or customer uploads are committed.

23 October 2026 — owner-authorized display fallback: the owner home highlights may use one of these existing synthetic portraits when the leading coach, member or player has no uploaded photograph. The card labels this as “صورة رمزية”. The choice is stored per academy in the existing versioned owner-home settings; it does not write a person photo, change identity, or replace an uploaded image. The remaining coach list uses a full-size silhouette when no image is available.
