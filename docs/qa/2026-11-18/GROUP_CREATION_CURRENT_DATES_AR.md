## GC-23 — فروع التحميل المكتوبة قبل التنفيذ

راجعت صور الجدول والمعاينة الحالية في سياق المالك، وحالات الرفض وعدم تأكيد الحفظ؛ أول تحميل يجب أن يحافظ على عنوان الشاشة والرجوع، ويعرض سببًا عربيًا وإجراء إعادة تحميل محددًا، دون حقل إدخال قبل اكتمال مصادر الهوية والمورد اللازمة. المراجعة لا تغير هوية التصميم أو صلاحية إنشاء المجموعة.

- اقطع شبكة خيارات البنية بـ TypeError، وأرسل 503، و JSON غير قابل للتحليل، وخيارات ناقصة المصفوفات؛ المتوقع رسالة عربية ثابتة بلا تفاصيل الاستثناء، ولا نموذج أو طلب كتابة. استعد الرد الصحيح ثم اضغط إعادة التحميل؛ تعود القوائم الفعلية بعد قراءة جديدة دون إعادة فتح الصفحة.
- أرسل مستويات بتركيب غير صالح، أو صلاحيات ليست مصفوفة نصية، أو موردًا معطل التركيب؛ المتوقع نفس الرفض الآمن دون انهيار render أو إتاحة نموذج جزئي.
- مع facilities.read أخّر استجابة المرافق؛ لا تُمكّن حقول الهوية قبل اكتمالها. ثم أرسل 503 أوبيانات تالفة؛ إعادة المحاولة تستعيد المورد الحقيقي المعتمد دون فقده بصمت أو إنشاء شيء.
- دون facilities.read ومع مصفوفة صلاحيات سليمة لا يُطلب مسار المرافق؛ يسمح النموذج بأعمال الجماعي غير المحجوزة وفق الحماية القائمة، ولا يُستنتج تفويض جديد.
- في المتصفح الفعلي: network ثم JSON تالف ثم بنية ناقصة ثم تعطل المرافق ثم استعادة المصدر الحقيقي. في كل مرحلة عنوان ورجوع واضحان، ولا نجاح كاذب أو POST إنشاء؛ قوائم المجموعة والحصص والتحصيلات قبل/بعد متطابقة. صور 390/1440 للحالة العربية وإعادة فتح النموذج.
