## البيانات والطريقة

محاكي iPhone واحد مؤقت على GitHub-hosted macOS؛ API وPostgreSQL وملفات الصور على نفس العامل وبقاعدة Demo جديدة. LegacyRegression بأكاديميتين مصطنعتين. إضافة هاتف تجريبي للإداري ومالك الأكاديمية الثانية وعضوية ثانية لمالك الأولى في القاعدة المؤقتة فقط. ينشئ ولي الأمر عبر API طلبين مصطنعين، أحدهما بباقة وصورة PNG محفوظة فعليًا والآخر دون باقة أو صورة. رفع الصورة برمجيًا تجهيز بيانات؛ لا يمثل اختبار منتقي ملفات iOS. لا تحويل أموال أو نشر staging.

يفتح الاختبار شاشة الإنتاج `NativeEnrollmentPaymentRead` في غلاف عربي بنفس الثيم. لا يمثل الوصول من الرئيسية. الأعطال 503 والبايتات التالفة والتأخير محقونة في نقل الصورة وحده؛ إعادة المحاولة الناجحة تنزل الأصل من API الفعلي. اختبارات الصلاحيات تستخدم الخادم الحقيقي دون محاكاة ردوده. فحص مالي كامل لصفوف التحصيل والإيصالات والفترات قبل وبعد؛ مقارنة تقرير المالك أيضًا.
