# تسليم V5 — الواجهة وسهولة الوصول

24 أكتوبر 2026. نطاق هذه الجولة هو إقفال واجهة لوحة الويب القائمة وفق طلب المستخدم، بلا وظائف أعمال جديدة.

## ما تغير

- **شكل موحد:** ألوان وخطوط وحقول وبطاقات وقوائم داخلية متسقة مع الرئيسية، بالمظهرين الفاتح والداكن.
- **وصول مباشر:** قائمة انتقال داخل كل شاشة للأقسام المسموح بها، ومسار واضح وزر رجوع إلى قائمة أو ملف موجود، حتى عند فتح رابط مباشر.
- **قوائم منظمة:** أعمدة مستقلة للهيكل والمدربين وحسابات الفريق والباقات والخصومات وأبناء الأسرة واللاعبين المميزين والتحصيلات والحضور والإيصالات؛ بطاقات بعناوين حقول على الهاتف.
- **أزرار أقل ازدحامًا:** إجراء أساسي ظاهر، وبقية الإجراءات القائمة في قوائمها؛ فلاتر إضافية داخل قسم قابل للفتح.
- **تبويبات أوضح:** الماليات تحفظ القسم في الرابط؛ بيانات المجموعة الأساسية تظهر داخل تبويب النظرة العامة بدل تكرارها فوق كل الأقسام.
- **المحتوى أولًا:** معرض الوسائط يعرض السجلات أولًا، والرفع من شاشته؛ الاستيراد يعرض نتيجة آخر دفعة مع مدخل واضح لملف جديد.
- **تفاصيل أسهل:** معلومات المنتج بجوار معاينة صغيرة، أسماء الرياضات واللاعبين بدل معرفاتهم الداخلية، منتقي ملفات بعناوين عربية، وإيصال قابل للطباعة بوضوح.
- **إصلاح أمني للتسليم:** Next وeslint-config-next من 16.4.0 إلى 16.4.3 بعد ظهور التنبيه والتحقق من npm audit. لا ترقية عامة أو تغيير متطلبات أعمال.

## التحقق

نتيجة النسخة المصححة: نجح **816/816 اختبار ويب في 160 ملفًا خلال 90.66 ثانية** وESLint بلا ملاحظات. ونجح TypeScript وبناء Next.js 16.4.3. شُغلت النسخة المبنية محليًا على 3278، وقُبلت عينات القوائم والمظهرين والمنتج والماليات والمعرض والاستيراد بعد تشغيلها. لا تُستبدل النتائج التاريخية بالمحاولات غير الناجحة.

- قبل الإصلاح الأمني: نجح 815/815 اختبار ويب، ثم 29/29 اختبارًا مركزًا بعد آخر تصحيح للأسماء والتنقل.
- نجح 13/13 اختبار عزل أكاديميات ومصادقة على قاعدة اختبار مستقلة جديدة؛ لم تستخدم قاعدة العرض لاختبارات الكتابة.
- فحص حزم الإنتاج بعد 16.4.3: صفر ثغرات مبلغ عنها. فحص كل أدوات التطوير أيضًا محفوظ؛ يوجد خمس نتائج في أدوات تطوير غير داخلة في حزم الإنتاج، ولا يُدعى أن فحص كل الحزم نظيف.
- 63 ملاحظة متصفح محفوظة، تشمل إعادة فحص النسخة المبنية، عند عروض 375 و768 و1280 بكسل؛ لم يظهر تجاوز أفقي لعرض المستند أو تنبيه فشل في هذه الملاحظات. يشمل السجل بعض إعادات الفحص بعد التصحيح، وليس عدد شاشات فريدة.
- المالك: الرئيسية، الماليات والرواتب، اللاعبون وأولياء الأمور والاشتراكات، الفروع والمجموعات والمدربون والموظفون والصلاحيات والخصومات، التحصيلات والمستحقات وبيان التشغيل والمصروفات والاتفاقات، الحضور والتقييمات، المنتجات والتغذية والأخبار والوسائط والسجلات الطبية، المباريات والتنبيهات والشكاوى والمتابعات والاستيراد والإعدادات، مع عينات ملفات وتفاصيل وإيصال.
- الإداري: دخول فعلي، قائمة اللاعبين وفتح ملف والرجوع، ومراجعة أن قائمة الانتقال تخفي الماليات والصلاحيات غير المتاحة لحسابه.
- على الهاتف: فتح قائمة التنقل ثم الماليات ثم الرواتب وإعادة التحميل؛ بقي التبويب المختار، وأغلقت قائمة الهاتف بعد الانتقال. مراجعة المظهرين وقوائم اللاعبين والتقرير والمنتجات والنموذج.

## حدود القبول

- جُردت 162 صيغة مسار في لوحة الويب وتستخدم الغلاف المشترك؛ المراجعة البصرية تغطي عائلات الشاشات المذكورة وعينات التفاصيل، ولا تُنسب مراجعة يدوية لكل مسار وكل سجل وكل حالة خطأ.
- المدرب وولي الأمر لم تُنفذ لهما رحلة متصفح جديدة في V5؛ نطاق الجولة لوحة إدارة الويب للمالك والإداري. لا تعديل لتطبيق Flutter أو إعادة ادعاء قبول جهاز حقيقي.
- فيديو شرح الصفحات مؤجل بطلب المستخدم، واختبار التحقق الحيوي على جهاز مادي غير منفذ لعدم توفر الجهاز. التفاصيل التاريخية محفوظة في V4.
- العرض محلي ببيانات اصطناعية. لا نشر إنتاجي أو اعتماد تشغيل إنتاجي من هذا التقرير، ولا إقرار بأثر رجعي باكتمال كل خطط V2/V3/V4.
- لم تُنفذ عمليات تحصيل أو نشر محتوى أو تعديل صلاحيات أثناء مراجعة المتصفح. لا reset أو seed أو migration على قاعدة العرض؛ شُغلت migrations لاختبار العزل المنفصل فقط.

## تشغيل العرض المسلم

الرابط المحلي: http://127.0.0.1:3278/dashboard/players — نسخة مبنية، وليست خادم تطوير. يعتمد على API العرض القائم في 5278 وقاعدة العرض الحالية دون إعادة تهيئة. تبقى الخوادم المحلية مرتبطة بتشغيل الجهاز؛ الرابط ليس استضافة عامة.

لإعادة تشغيل الويب بعد إيقافه، من جذر المشروع، مع تشغيل API العرض المناسب:

```sh
API_INTERNAL_URL=http://127.0.0.1:5278 ACADEMY_WEB_DIST_DIR=.next-v5-release npm run start -w @academy/web -- --hostname 127.0.0.1 --port 3278
```

لإعادة البناء يُستخدم نفس متغير المجلد مع `npm run build -w @academy/web`. لا تعاد تهيئة قاعدة العرض للتشغيل. لا تحفظ كلمات مرور أو إعدادات اتصال في هذا المستند.
