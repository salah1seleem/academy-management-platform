### تصحيح دليل بيئة iOS

فشل API الأول في حجز5260 لأنه مستخدم من خدمة العرض السابقة (PID16506، الأب16504). فحص المنافذ الأول رشّح اسم العملية dotnet فأغفل الملف التنفيذي Academy.Api؛ يجب فحص المنفذ نفسه بلا ترشيح الاسم. لم تُوقف الخدمة القديمة. لذلك جولة iOS التي اجتازت التنقل للأدوار الأربعة ولقطاتها الأولى ليست قبولًا معزولًا: استعملت خدمة الديمو القديمة. نفذت دخول OTP وقراءات الشاشات فقط، دون حفظ مال أو اشتراك أو إعداد؛ لا ننسب لها تحقق حفظ الهدف أو عزل البيئة، ولا نستنتج عدم حدوث أحداث جلسات أو قياس عرض تلقائي. لم يُنفذ reset أو تصحيح بيانات قديمة لإخفاء المحاولة.
