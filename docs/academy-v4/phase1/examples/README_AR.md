# ملفات تجربة الاستيراد المترابط

هاتان نسختان حرفيتان من تنزيل API الفعلي ثم اختبار رفع المثال كما هو؛ لم يُعاد تصديرهما بأداة الجداول.

- `i-academy-one-blank.xlsx`: قالب فارغ مع الدليل والأنماط وإعدادات المصدر.
- `i-academy-one-10-fictional-players.xlsx`: 10 لاعبين خياليين، 11 تسجيلًا رياضيًا، 9 أسر، مدربان، رياضتان، ومشاركات بطولة متنوعة.

مخصصتان لأكاديمية Demo `10000000-0000-0000-0000-000000000001` ومصدر ثابت `academy-opening` وتاريخ قطع Demo `2026-09-28`. استعمل Download API من الأكاديمية الحالية للحصول على ملف سياقها؛ لا تنقل metadata أكاديمية بوصفها تفويضًا. لا تمثل الملفات اشتراكات إنتاج أو قبضًا اليوم، ولا تحتوي أسرارًا أو أطفالًا حقيقيين. يمكن حفظها وإعادة رفعها بنفس المصدر والأكواد دون تكرار.

أوراق المدربين والبطولات والفرق ضمن العقد؛ الولي داخل ورقة الأعضاء بكود الأسرة والهاتف النصي. الخاص/شبه الخاص يتطلب مجموعة قائمة بمورد وسعة معتمدين. الأرصدة الافتتاحية اختيارية وليست إيصالات. الدليل التفصيلي داخل الملف و`../DEMO_AR.md`.

الهواتف محفوظة shared strings وبصيغة نص `@`، والأوراق RTL. قارئان مستقلان أكدا القيمة والأصفار الأولى. عارض PNG المستقل أسقط الصفر الأول بصريًا ولم يعكس الأعمدة؛ لا نعتمد صورته لإثبات مظهر Microsoft Excel. لم يُختبر الملف داخل تطبيق Excel نفسه.
