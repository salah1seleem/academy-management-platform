# أكاديميتي V4.1 — تحسين الموبايل أولًا

اعتماد صلاح المباشر، 20 أكتوبر 2026، من المرفق «أكاديميتي — V4 | تنفيذ الموبايل أولًا وتحديث الرئيسية على الويب». يطور V4.0 ولا يستبدل ضوابط المال والعزل وحقوق الأطفال. المرجع التنفيذي: `docs/academy-v4/MOBILE_FIRST_REFINEMENT.md`.

النطاق 18 نقطة: نظام التصميم وصور اصطناعية محفوظة؛ رأس وفلاتر شهر متحرك؛ ملخص و4 مؤشرات؛ الاشتراكات والتحصيل اليومي/الشهري؛ قائمة تشغيلية صحيحة؛ ترتيب الرئيسية؛ 3 قرارات ذكية؛ تنبيهات مشتركة وإرسال داخلي مؤكد؛ مدربون بالترتيب حسب التقييم؛ أعلى5 أعضاء ومكافآت المحرك القائم؛ أبرز اللاعبين وميزانية3نجوم لكل مدرب/فريق/شهر؛ مباريات المالك؛ مباريات المدرب؛ تقارير مبسطة؛ المزيد وفيديو شرح حسب الدور والشاشة؛ مساحة طفل واحد لولي الأمر؛ قوائم اللاعبين وحالة اشتراكهم؛ الأخبار والإعلانات أخيرًا.

الموبايل Flutter الحالي هو الهدف الأساسي، مع تماثل رئيسية المالك على الويب. لا يُعد responsive Web تنفيذ موبايل. العربية RTL، تصميم داكن هادئ، صور فعلية اصطناعية مرتبطة بالسجلات، لا نسب أو أهداف أو معاملات مختلقة. الديمو معزول فقط. الفترة الافتراضية شهر تقويمي متحرك إلى اليوم المحلي الفعلي؛ المباريات كل التواريخ؛ تغيّر تعليمات التاريخ الأقدم في هذين السياقين فقط.

اختبارات وظيفية مجمعة بعد الميزات، مع فحص بناء وأنواع أثناء العمل، ثم تحقق Flutter فعلي بأبعاد هاتف صغير واعتيادي وويب وصور صادقة. لا SMS/push حقيقي أو إنتاج أو دفع أو عميل حقيقي. غياب الصور المرجعية/محتوى الفيديو يسجل بلا ادعاء مطابقة أو تشغيل فيديو غير مقدم. تحفظ خريطة الـ18 نقطة وأدلتها بعد كل شريحة.
