# V5.23 — تجهيز DigitalOcean App Platform

اعتماد المستخدم الصريح: App Platform بدل VPS لتسهيل التشغيل. يضاف إلى V5.22 دون تغيير الموافقة الأصلية.

- البدء من main الحالي وفرع مستقل وإعادة استخدام Dockerfiles.
- API وNext.js وManaged PostgreSQL17، وعامل الاستيراد داخل API.
- وسائط Spaces خاصة مع إبقاء إثبات الهوية والأكاديمية والصلاحية الحية لكل تنزيل، ومفاتيح Data Protection دائمة ومشفرة خارج ملفات الحاوية.
- HTTPS وربط same-origin وفحوص صحة ومهمة migrations قبل النشر، دون شبكات Compose الثابتة.
- تحقق مناسب لاستمرار الوسائط والجلسات وبيان حدود التحقق، وجرد OTP وإشعارات الموبايل دون تكامل جديد.
- PR وتقرير عربي بالتكلفة والعوائق؛ لا شراء أو نشر أو DNS أو بيانات عملاء أو أسرار.

الشريحة AP-01؛ توصية Sol/High لتخزين خاص وجلسات، دون تغيير إعدادات المستخدم أو subagents. الإغلاق مشروط بالدليل الفعلي وحدود ما لم يُختبر.
