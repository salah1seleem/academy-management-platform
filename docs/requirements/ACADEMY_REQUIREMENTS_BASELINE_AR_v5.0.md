# I Academy One — V5: إقفال الواجهات وسهولة الاستخدام

اعتماد النطاق: طلب المستخدم المباشر في 24 أكتوبر 2026، إضافة إلى v4.10 وسلسلتها دون تعديلها.

- V5 مرحلة تسليم للمنتج القائم، لا توسعة أعمال أو استئناف مستقل لبنود V2/V3 القديمة.
- اعتماد جودة الرئيسية مرجعًا للشاشات الداخلية: الألوان والخطوط والمسافات والتباين والقوائم والأزرار، مع دعم العربية وRTL والهاتف.
- الوصول المباشر للوظائف المخولة؛ رجوع مفهوم إلى القائمة أو الملف، وإجراءات رئيسية محدودة، والباقي في قائمة واضحة.
- القوائم ذات أعمدة معنونة ومحاذاة مريحة وبحث وفلاتر وصفحات حيث يدعمها المصدر الحالي. تستخدم التبويبات لتقسيم أقسام الملف أو مساحة العمل بدل تكديس صفحات طويلة. الإنشاء منفصل عن القائمة.
- فحص الواجهة قبل تعديلها ثم مراجعتها بصريًا ووظيفيًا بعد التعديل. لا يُستنتج قبول شاشة من نجاح اختبار مكون أو عمل الرئيسية.
- تُحفظ الوظائف والبيانات الحالية والصلاحيات وعزل الأكاديمية والفرع والرياضة والأسرة وقواعد الأموال. لا خدمات خلفية جديدة أو تغيير مالي أو نشر إنتاجي ضمن هذه المهمة.
- يستمر تأجيل فيديو الشرح، ويظل اختبار التحقق الحيوي على جهاز حقيقي غير منفذ لعدم توفر الجهاز؛ لا يُعاد فتح هذين المسارين تلقائيًا.
