# I Academy One — V4.8: ترتيب رأس ملخص التحصيل

إضافة إلى v4.7 وسلسلتها بطلب المستخدم المباشر في 23 أكتوبر 2026:

- نقل زر «ضبط هدف التحصيل» مقابل «التحصيل خلال الفترة» في رأس الكارت، مع خط أوضح وأثقل.
- زيادة وزن خط أسماء الفروع، بما فيها «كل الفروع».
- تقليل الفراغ الناتج وارتفاع مساحة الملخص لرفع التحصيل الأسبوعي، مع الحفاظ على تقسيم البيانات والشعار وقابلية تكبير النص.

لا تغيير لحساب التحصيل أو الصلاحيات أو نطاق البيانات. أدلة التنفيذ في سجل التسليم.
