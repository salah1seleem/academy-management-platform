# V5.3 — تنقيح رئيسيات الموبايل الأربع

توجيه المستخدم المباشر26أكتوبر2026، مضاف إلىv5.2وسلسلتها دون تعديلها أو تضييقR01–R19وA01–A12.

- هذه الدفعة لشكلHomeالمالك والإداري والمدرب وولي الأمر فقط؛ لا وظائف أعمال أو صلاحيات أو توسع مباريات.
- يكبر الشعار الأساسي بالهيدر وزرHome، مع ملء المساحة الآمنة داخل حد الدائرة/المربع دون تشويه أو قص أجزاء الهوية. يستخدم الشعار القانوني نفسه دون رفع نسخة أخرى.
- الخلفية مزيج خافت من ألوان الشعار الفعلية، متناسق مع المظهر الأبيض؛ لا لون مفرد عشوائي. شعار الخلفية واضح في المنتصف بمكان مستقل لا تغطيه أزرار الحساب والتنبيهات. يصغر اسم الأكاديمية ويظل قابلًا للفهم والوصول.
- تعاد حركة شريط الإجراءات السلسة ذهابًا وإيابًا للأدوار الأربعة، بإجراءات الدور المصرح بها القائمة. تقل المسافة بين أيقونة الإجراء واسمه ويصغر شكله. تتوقف الحركة مع اللمس والصفحات المغطاة وتقليل الحركة. هذا تعديل صريح لشريط الإجراءات فقط، ولا يعيد تحريك بطاقات الأبناء أو بقية القوائم تلقائيًا.
- كارت اشتراكات الأكاديمية/نطاقك أقصر، وله سطح فاتح متصل بهوية الهيدر. يُحذف صف الهوية الصغير واسم الأكاديمية المكرر، ويتقارب العنوان والعدد. تستعمل المساحة المقابلة للشعار الكبير/أثره البصري، دون اختراع عدد أو تغيير وحدات التسجيلات واللاعبين أو شروط الفعال والمنتهي.
- تُراجع النتيجة الفعلية بالمظهرين والمقاسات الصغيرة والنص الكبير. تبقى جلسات اختبار المستخدم الأربع والخدمات الثابتة دون إيقاف أو تبديل أثناء عمله؛ تسلّم المعاينة الجديدة منفصلة مع دليل صادق.
