## تغيير CH-013 — فصل دخول لوحة الإدارة عن تطبيقات المستخدمين

- صفحة دخول Web Dashboard نموذج واحد بلا تبويبات «فريق الأكاديمية» أو «ولي أمر».
- دخول Web Dashboard متاح فقط لعضوية `AcademyOwner` أو `AcademyAdmin` النشطة.
- المدرب وولي الأمر لا يسجلان الدخول إلى Web Dashboard؛ يستخدم كل منهما تجربة الموبايل المخصصة له.
- يطبق المنع على الخادم، ولا يقتصر على إخفاء عناصر الواجهة.
- لا يلغي هذا التغيير دور المدرب أو ولي الأمر، ولا صلاحياتهما المقيدة أو رحلاتهما داخل تطبيق الموبايل.

المتطلبات المتأثرة: `AC-GOV-004`, `AC-IAM-001`, `AC-IAM-004`, `AC-IAM-006`, `AC-DEL-003`, `AT-002`.
