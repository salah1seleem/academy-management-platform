# I Academy One — V4.3: تجهيز الخلفية وانتظار التصميم النهائي

المصدر: طلب المستخدم المباشر في 21 أكتوبر 2026 بعنوان «Phase 1: Backend Readiness, Functional Completion & Design Preparation». إضافة إلى v4.2 وسلسلتها، دون تعديل أي baseline سابق أو سجل الموافقة. لا يُعد هذا إقرارًا باكتمال V4 أو V2/V3.

- التصميم النهائي قيد إعداد Claude Design. ZIP السابق مرجع مبدئي لفهم الشاشات والرحلات فقط؛ لا تنفيذ أو إعادة تصميم نهائي للموبايل أو الويب أو ترتيب ملاحة/ألوان/خطوط بناءً عليه الآن. يتقدم هذا القيد على تعليمات المطابقة البصرية في المرفق السابق.
- التوفيق يشمل النقاط 00–25 في [النص المرجعي المحفوظ كما ورد](../academy-v4/phase1/reference/LINKED_REQUIREMENTS_00_25.md)، مع حالة Completed/Partially Completed/Missing/Blocked ومصادر التنفيذ والاختبار والمتبقي. النسخة المحفوظة توثيق للطلب السابق، ولا تعيد تفعيل تعليماته البصرية المؤجلة.
- الأولوية لاستيراد Excel مترابط فوق النماذج وآلية staging/background publication القائمة: الهيكل والمدربون والجداول والباقات والعروض والأعضاء وأولياؤهم والاشتراكات والبطولات وروابطها، بأكواد مقروءة. فرّق بين المجموعة والفريق، وامنع اعتماد ربط غير محسوم. نموذج فارغ ومثال 10 لاعبين خياليين، واختبار 200–300 لاعب مترابط، وتحقق/معاينة/تأكيد ونشر آمن وإعادة استيراد بلا تكرار. لا تحصيل أو دفع أو حضور أو نتائج مصطنعة.
- خصم استثنائي اختياري عند اشتراك جديد للمالك وإداري مفوض صراحة: قيمة أو نسبة مع سبب، وإذن مستقل، وإعادة حساب خادمية، وحفظ الأصل والخصم والصافي والمنفذ والتوقيت بسجل مدقق. لا تعديل لسعر الباقة أو إنشاء عرض دائم أو جمع خصومات متعارضة. يبقى شرط المالك القائم للإعفاء الكامل ما لم يعتمد تغيير لاحق.
- فحص الانحدار والأمن والأداء للمسارات المتأثرة: academy/branch scope، التفويض، التسجيل والتجديد والتحصيل والحضور والحصص والاستيراد وإعادة الإرسال والإشعارات القائمة والقوائم الكبيرة. أصلح العيوب المثبتة فقط بدليل اختبارات/استعلامات، دون إعادة معمارية أو نطاق V2/V3 مستقل.
- إعداد خريطة الربط بالموبايل والويب والمكونات التي تحتفظ بها الواجهات النهائية. اختبارات API لا تثبت رحلة Flutter/الويب المرئية. بعد وصول التصميم النهائي يُوفق مع هذه المتطلبات والعمل المنفذ ثم تُنفذ الواجهات واختباراتها.
- تقارير التقدم والنتيجة بالعربية، مع فصل المنفذ المختبر عن المؤجل وغير المتحقق. لا نشر أو رسائل حقيقية أو بيانات عميل أو موافقات روتينية إضافية. جميع ضوابط استقلال المنتج والمال والخصوصية والتغذية المعلوماتية والعزل السابقة مستمرة.
