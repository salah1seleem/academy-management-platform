# تحديث المتطلبات v1.7 — فترة الحصص الافتراضية

التاريخ: 8 أكتوبر 2026. المصدر: طلب المالك المباشر، إضافة إلى v1.0–v1.6 دون تعديلها.

## CH-024 — الحصص بتاريخ اليوم

في قائمة الحصص يبدأ «من تاريخ» و«إلى تاريخ» بتاريخ اليوم الفعلي في `Africa/Cairo`، وليس تاريخ Demo المرجعي الثابت. يمكن تعديل أو إفراغ التاريخين لعرض فترة أخرى أو كل الحصص. «مسح الفلاتر» يعيد فلترَي التاريخ إلى اليوم ويزيل بقية الفلاتر. لا تغيير لجدول المجموعة أو الحصص أو البيانات المحفوظة.
