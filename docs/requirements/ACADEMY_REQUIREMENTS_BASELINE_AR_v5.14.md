# V5.14 — إعادة تصميم شاملة للتطبيقات

توجيه المستخدم29أكتوبر2026 يجيز إعادة ترتيب وتصميم كل الشاشات بلا تقييد بالمطابقة البصرية السابقة، بما فيها Splash والشعار والدخول وOTP واختيار الأكاديمية، وتطبيقات المالك والإداري والمدرب وولي الأمر.

القبول: تصميم حديث متسق، مهمة رئيسية واضحة لكل شاشة، تنقل ورجوع متوقعان، كثافة مناسبة للموبايل، قوائم غنية بالمعلومات، حالات تحميل/فراغ/خطأ/نجاح، ونماذج واضحة وتأكيد مناسب قبل إرسال الطلب. مراجعة فعلية للرحلات الرئيسية والأوضاع الأربعة، واختبارات العرض وتدفقات العمل والعزل.

يحل هذا التوجيه محل القيود البصرية السابقة على مطابقة مراجع HTML أو تجميد تصميم الفاتح والداكن. تبقى هوية I Academy One وهوية الأكاديمية قابلتين للتعرف. تبقى العربية وRTL والأعمال والصلاحيات وعزل الأكاديميات والمعاملات والبيانات الخيالية كما هي فيv5.13 وسلسلتها؛ لا يجيز التوجيه إضافة خدمات أو تغيير أهلية أو أسعار أو صلاحيات أو تحصيل.
