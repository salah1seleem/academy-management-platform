# V5.6 — تأكيد استثناء العمر وإرشاد إنشاء الأكاديمية

توجيه27أكتوبر2026 المباشر، إضافة إلىv5.5 وسلسلتها.

- إذا كان اللاعب خارج عمر المجموعة: رسالة واضحة بسنوات الميلاد المقبولة، واختيار إكمال الطلب أو إلغاء الطلب. الإدارة المخولة بالتسجيل يمكنها الإكمال بعد التأكيد؛ لا ترفض المعاملة آليًا لهذا السبب وحده.
- يؤكد الخادم علم الإدارة بالاستثناء ويسجل منفذ التأكيد داخل المعاملة نفسها؛ تبقى صلاحيات الأكاديمية والفرع والسعة والمنتج والتحصيل وعدم التكرار. المستقبل ليس تاريخ ميلاد صحيحًا، ولا يشمله الاستثناء.
- إصلاح إنشاء الأكاديمية: توضيح كود الرابط القصير والفريد مع أمثلة، ورسالة خاصة بالحقل بدل الخطأ العام. لا يغير ذلك مطابقة هوية المالك القائم أو حماية مشغل المنصة.
