# V5.5 — إصلاح تسجيل اشتراك الإداري، 27 أكتوبر2026

توجيه المستخدم المباشر، إضافة إلىv5.4 وسلسلتها؛ لا تعديل للموافقات القديمة.

- إصلاح إنشاء الاشتراك بصلاحيات الإداري، وإظهار سبب رفض مفهوم بدل رسالة422 عامة.
- تمييز الحقول المطلوبة بنجمة حمراء: اللاعب الجديد/اختيار لاعب موجود، اسم اللاعب وميلاده عند إنشاء جديد، ولي الأمر والهاتف، الفرع والرياضة والباقة.
- المجموعة اختيارية في الاشتراك الجماعي العادي؛ التسجيل غير المسكن لا ينشئ حضورًا أو تسكينًا وهميًا. الخاص وشبه الخاص يحتفظان بضوابط المورد والسعة والمستوى.

- اختبار الحفظ المالي الذري وعدم التكرار والعزل بأكاديمية ثانية، مع بيانات خيالية. لا seed/reset لبيئة اختبار المستخدم ولا توسع مباريات.
