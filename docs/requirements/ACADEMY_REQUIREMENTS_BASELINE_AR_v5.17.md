# V5.17 — جاهزية التحصيل والقائمة الجانبية ومقترحات الأزرق

توجيه المستخدم30أكتوبر2026، يضاف إلىV5.16:

1. إصلاح اختيار التحصيل النقدي عند الاشتراك والتجديد؛ تمييز توقف النقدي أو غياب الوردية عن خطأ الشبكة وتغير البيانات. الحفاظ على الصندوق المخول والوردية الشخصية وعزل الأكاديمية والتحصيل الذري ومنع التكرار. لا تفعيل تلقائي للنقدي أو فتح عهدة أو تغيير تفويض.
2. إزالة رابط «فرص التجديد» من قائمة عمليات الأكاديمية بالداشبورد، مع حفظ المسار والوظائف القائمة خارج هذه القائمة.
3. فتح أقسام القائمة لأسفل دون إغلاق قسم أعلى يحرك موضع القسم الذي اختاره المستخدم؛ مراجعة فعلية للتمرير.
4. تجهيز ثلاثة مقترحات لونية مائية باسم «أزرق»، على رئيسية المالك وولي الأمر مع الأزرار وبنفس التخطيط والهوية. ينتظر تطبيق اللون اختيار المستخدم الصريح. عند اعتماد اللون تطبق لوحة الألوان على جميع شاشات التطبيقات الأربعة، ويصبح اسم المميز «داكن مميز»؛ الفاتح والملعب والمحتويات والوظائف محفوظة.

المقترحات ليست اعتمادًا لتطبيق أي لوحة ألوان الآن. توثيق التحقق والحدود في سجل التسليم.
