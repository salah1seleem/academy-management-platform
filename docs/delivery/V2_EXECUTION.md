## GAP أولي يجب إغلاقه باختبارات

الموجود يُعاد استخدامه: auth/tenant memberships، Player/SportEnrollment، باقات وتجديدات وتحصيل idempotent، حضور وتقييمات منشورة، محتوى وتغذية، payroll أساسي، نقل مجموعات وجدول، manual proof، مباريات وهوية، Web وFlutter للولي والمدرب والمالك. مصفوفة CRUD/branch الدقيقة والاستيراد والتجديد الجماعي كانت غير مكتملة في v1.9؛ لا تُسقط من V2.

غير موجود أو يحتاج توسعة جوهرية: entitlement/config lifecycle، هوية منصة منفصلة، Admin native، مرفق/حارة/حجز/سعة ذرية، ledger receivables/allocation، توزيع تكلفة مقفل، hybrid worklog، external contracts، schema import، learning levels/plans، complaints/calendar audience، tasks/insights/simulator/CRM/help/ads/consent/outbox. هذه فجوات حقيقية وليست وظائف مكتملة من مجرد تشابه أسماء.

كل معرف في `../requirements/v2/acceptance_cases.json` حالة المصدر له `NOT_EXECUTED_ON_PRODUCT`. لا يُغيّر الملف المرجعي؛ تسجل نتائج المنتج بجانب مسار الاختبار وإصدار commit في هذا السجل. تشغيل صفر اختبار/مزود غائب لا يُسجل Passed. اختبارات CI والـProduction والتكاملات الحقيقية لم تُشغّل بعد لهذه الدفعة.
