العمل في مشروع Academy Management Platform / iAcademy One المستقل. لم نصل إلى كود الأهلي أو قواعده أو أسراره، ولم نشترِ موارد أو ننشر أو نغيّر DNS أو بيانات عملاء.

الفرع: `codex/vps-compose-readiness`. [PR1 مسودة إلى main](https://github.com/salah1seleem/academy-management-platform/pull/1). حُفظ المصدر المحلي قبل التعديل، بما فيه العمل اللاحق لـ21 أكتوبر. أثبتت التواريخ والأنساب أن فرع16 أقدم من تنفيذ15؛ لم يُستبدل العمل برقم فرع أكبر. main ما زال دون دمج.

## نسخة التصوير

- 300 لاعب خيالي داخل Professional، و150 ولي أمر، و18 مجموعة.
- الفروع: الرحاب ومدينتي والشروق. الرياضات: 165 كرة قدم، و90 سباحة، و45 كرة سلة.
- أكاديمية ثانية ولاعب خيالي واحد لاختبار العزل. رُفض وصول المالك وولي الأمر إليه فعليًا بـ404، قبل إعادة تشغيل API وبعدها.
- اللوجو والأطقم الثلاثة من الأصول الموجودة. السعر 650 جنيهًا والمخزون أرقام عرض اصطناعية، وليست بيانات بيع حقيقية.
- رئيسية المالك ببانر وشريط عمليات متحرك فوق الاشتراكات. المدرب يفتح المجموعة ولاعبيها، ويقيّم شهريًا دون فتح حصة. حضور اللاعبين يظهر عند التفويض فقط، مع إعادة فحص الخادم للصلاحية ونطاق المجموعة.
- المواعيد والتواصل داخل قسم اختياري في المجموعة، لتظهر قائمة اللاعبين مبكرًا. لا رفع وسائط حصة من مجموعة بلا جلسات فعلية.

نجحت رحلة الموبايل على محاكي Professional المستقل مرتين: 38 ثانية ثم 33 ثانية. شملت طلب الطقم من ولي الأمر، ورفع إثبات موسوم بأنه تجريبي وليس تحويلًا بنكيًا، ومراجعة المالك، وتأكيد الطلب للأسرة، وتطابق زيادة تقرير المنتجات، وظهور المخزون للمالك. أعاد الاختبار الاعتماد وتحقق من عدم خصم المخزون ثانية.

المخزون الفعلي: 24 → 23 → 22 بعد عمليتي اختبار مستقلتين. يوجد طلبان مؤكدان بقيمة 650 لكل منهما، ومجموع 1300 جنيه تجريبي. لم توجد أموال أو تحويلات حقيقية. رفع الإثبات عبر API لا يثبت منتقي ملفات الجهاز.

حُفظت سبع لقطات وروجعت فعليًا: المالك، والمدرب، والمجموعة، ومراجعة المنتج، والإثبات، والمخزون، وعودة المالك للرئيسية. صور الحزمة الست اصطناعية؛ ملفات reference-child غير موجودة في حزمة الموبايل أو سياق Docker أو Git. بقيت الملفات الأصلية الخاصة محفوظة محليًا.

## Docker وعوائق الإنتاج

Compose يشغل API وNext.js وPostgreSQL17، مع migrator منفصل وصلاحيات CRUD للتشغيل، وفحوص صحة، ووسائط ومفاتيح دائمة، وbackup/restore إلى هدف جديد. عامل الاستيراد داخل API.

راجع [دليل VPS](../../infra/vps/DEPLOYMENT_AR.md) و[سجل التحقق](../../infra/vps/VALIDATION_AR.md). لا شراء أو نشر أو DNS أو دمج.

OTP الحقيقي غير منفذ ويعيد501 في الإنتاج؛ لا يوجد fallback برمز Demo. تبقى التهيئة الآمنة لأول مالك/منصة وMFA والاسترداد، وTLS والأصول وRPId الفعلية، وقنوات الدفع والإشعارات المطلوبة، والنسخ المشفرة خارج الخادم والمراقبة وتجربة staging، ونجاح الفحوص المطلوبة، شروط قبول الإنتاج.
