# تهيئة أول مسؤول منصة بمصادقة فعلية

الأداة إجراء تشغيل صريح، وليست تسجيلًا عامًا أو endpoint أو seed. لا يشغّل بدء API العادي هذا الإجراء. لا تُطبق أي خطوة أدناه على staging أو الإنتاج دون مراجعة الهدف وتفويض التشغيل.

## الشروط

- استخدم صورة API المراجعة نفسها وبيئة التشغيل الخاصة الحالية، من جلسة طرفية خاصة تفاعلية؛ لا تنسخ ملفات البيئة أو أسرارها إلى Git أو الشات أو سجلات CI.
- القاعدة مهاجرة مسبقًا، والاتصال بحساب runtime محدود الصلاحيات. لا تستعمل doadmin ولا تعدّل grants لأجل التهيئة. تبقى TLS VerifyFull وشهادة CA ومخزن المفاتيح المشفر وSpaces الخاص كما هي في App Platform.
- لا يوجد أي صف سابق في PlatformAdministrators، حتى لو موقوفًا. البريد جديد ولا يخص حساب مالك أو موظف أو عميل قائم. هذه الأداة لا ترقي حسابًا قائمًا، ولا تعيد تمكين مسؤول، ولا تغير كلمة مروره أو TOTP.
- يلزم تطبيق مصادقة TOTP وخزنة خاصة لحفظ نسخة مفتاح المصادقة. لا تُنشئ هذه الأداة مسار استرداد عبر البريد أو أكواد استرداد؛ الاسترداد باستخدام نسخة مفتاح TOTP المحفوظة. فقد الهاتف والمفتاح معًا يحتاج إجراء تعافٍ منفصلًا ومصرحًا، وليس إعادة تشغيل bootstrap.

## التشغيل

من جلسة طرفية خاصة داخل بيئة الخدمة المعتمدة، وبوجود إعدادات التشغيل المعتادة في البيئة:

```sh
dotnet Academy.Api.dll --bootstrap-platform-admin
```

للتطوير فقط يمكن تشغيل المشروع بالأمر نفسه بعد `dotnet run --project apps/api/src/Academy.Api --configuration Release --no-build --`.

الأداة تعرض اسم الخادم والقاعدة، وتطلب كتابة اسم القاعدة لتأكيد الهدف، ثم البريد والاسم وكلمة المرور وتأكيدها بإدخال مخفي. تعرض مفتاح TOTP مرة أثناء التهيئة؛ يضيفه صاحب الحساب إلى تطبيق المصادقة، ويحفظه في خزنته، ثم يكتب رمز التطبيق بإدخال مخفي. لا تستخدم screen recording أو terminal logging أو مشاركة الشاشة خلال عرض المفتاح. لا تمرر بيانات الدخول في command line أو shell history أو ملفات أوامر.

لا يُحفظ مسؤول قبل نجاح التحقق من كلمة المرور وTOTP. الإلغاء أو الرمز الخاطئ يتراجع عن إنشاء المستخدم والمفتاح والمنح وسجل التدقيق. قفل PostgreSQL داخل المعاملة يمنع إنشاء مسؤولين متزامنين بالأداة. يُستهلك رمز التسجيل لمنع إعادة استخدامه فورًا في الدخول؛ انتظر الرمز التالي في التطبيق ثم افتح `/platform/login`.

الأمر لا يبدأ خادم HTTP أو workers، ولا ينفذ migrations أو demo seed أو reset. يرفض الجمع مع `--migrate-only` أو `--reset-football-demo`، ويرفض Demo والإدخال/الإخراج المعاد توجيهه. تشغيل الأداة ليس إذنًا لتغيير إعدادات الخدمة أو إنشاء موارد مدفوعة.

## القبول بعد التهيئة

1. دخول طبيعي بكلمة المرور ورمز TOTP متجدد إلى إدارة المنصة، دون حساب Demo أو fixed OTP.
2. رفض الرمز الخاطئ وإعادة استخدام الرمز، ورفض وصول مالك الأكاديمية إلى إدارة المنصة.
3. سجل `platform.bootstrap` دون كلمة مرور أو مفتاح أو رمز مصادقة؛ عدم إنشاء AcademyMembership للمسؤول.
4. حفظ مفتاح TOTP خارج الجهاز، وفصل حفظ أسرار الاستعادة ونسخ قاعدة البيانات وفق خطة التشغيل. لا تدّع قبول التعافي الكامل دون تجربة معزولة مصرح بها.

اختبارات `PlatformAdministratorBootstrapTests` تنشئ قواعد PostgreSQL محلية مؤقتة بأسماء عشوائية على loopback فقط، وترفض اتصالًا ليس ضمن `academy_test*`. لا تستخدم قاعدة staging أو الإنتاج للاختبارات.
